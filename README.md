## 📌 Project Overview

This project uses OCR (Optical Character Recognition) and Computer Vision techniques to extract and recognize medication names from prescription images. The system helps digitize medical prescriptions and improve healthcare automation.

---

## ⚙️ Technologies Used

- Python
- OpenCV
- Tesseract OCR
- Flask / FastAPI
- NumPy

---

## 🚀 Features

- Extract text from images
- Clean OCR output
- Detect medication names
- API for integration
- Image preprocessing

---

## 🧠 How It Works

1. Input image uploaded
2. Image preprocessing (grayscale, filtering)
3. OCR text extraction
4. Text cleaning & processing
5. Output medication names
